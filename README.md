🛒 ShopSphere – E-commerce Marketplace

ShopSphere is a full-stack e-commerce web application that allows users to browse products, search by category, manage their shopping cart, and place orders. It also includes an admin dashboard for managing products and customer orders.

✨ Features

- Browse products
- Search products
- Filter products by category
- Add new products
- Edit product details
- Delete products
- Shopping cart functionality
- Update product quantities
- Checkout and order placement
- My Orders section
- Admin authentication
- Admin order management
- Update order status
- PostgreSQL database integration

🛠️ Tech Stack

Frontend

- React.js
- Vite
- JavaScript
- CSS

Backend

- Node.js
- Express.js
- REST API

Database & Authentication

- PostgreSQL
- JWT Authentication

🚀 How It Works

1. Browse available products.
2. Search products or filter by category.
3. Add products to your shopping cart.
4. Increase or decrease product quantities.
5. Place orders using checkout.
6. View your orders in My Orders.
7. Admin manages products and customer orders.
8. Admin updates order statuses.
